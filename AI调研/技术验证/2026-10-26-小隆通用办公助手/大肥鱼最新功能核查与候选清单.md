## 桌宠功能（维护者文档证据）

| 功能 | 具体含义 | 可借鉴的小隆增量 |
| --- | --- | --- |
| 事件驱动状态 | 思考、查找、修改、运行、验证、等待、完成、出错 | 将现有真实作业/工具事件映射为机器人不同动作；不显示假进度 |
| 阶段与待办气泡 | 展示项目、步骤及上游确实提供的待办完成情况 | 已有短气泡可增加当前文件/当前步骤；未知总量不显示百分比 |
| 多任务显示 | 聚合多个会话，需要注意的任务优先 | 先实现多会话和作业归属，再做桌宠任务切换；当前单任务不能假装并行 |
| 互动与随机待机 | 摸头、身体、尾巴、拖动落地、伸懒腰/哈欠 | 保留小隆形象，另做动作素材或绑定，不直接套人物帧 |
| 动态与音效设置 | 大小、气泡、声音、活跃程度、减少动态 | 可配置完成提示与静音，优先避免打扰老板 |
| 余额 | API Key及登录账户来源区分 | 小隆可先只接自己已配置的API余额；失败时标过期，不猜余额 |
| 页面内轻量角色 | 可选，默认关闭 | 当前已有桌宠，不必同时复制一只到界面占空间 |

证据：[维护者README](https://github.com/QCYTSN/dsh-dafeiyu/blob/main/README.md)、[动作触发说明](https://github.com/QCYTSN/dsh-dafeiyu/blob/main/docs/animation-behavior.md)。大肥鱼自身不会读取屏幕；不把它说成能看见当前Excel或自动控制鼠标的插件。

## 建议用户优先挑选（proposed）

1. 多会话：不同工作不混上下文，能找回此前报告；同时明确每条会话的资料范围。
2. 成果直接预览：文档或表格在右侧查看，再用对话改稿，减少反复打开文件。
3. 完成/失败/等待提醒：以真实任务事件为准，支持静音；比装饰动作更早产生办公价值。
4. 定时周报与提醒：先明确电脑/程序关闭后的行为、失败补跑和是否自动读资料，不假设永远在线。
5. 联网查资料与来源：可查公开资料，企业统计继续走受控数据，网页不能充当公司事实。
6. 动作和轻互动：小隆看起来会“工作”和“等你”，需要新动作素材，不承诺单个GLB自动有动画。
7. API余额/用量：帮助看费用；余额与单次Token估价分开显示，查询失败不装作成功。

OCR/扫描件、成熟PPT生成、语音连续交互、控制Excel界面、企业ERP权限/SQL准确性，不能仅凭这些资料认定该桌宠已内置解决；若选入小隆需另做具体方案和验证。用户尚未选择本清单任何新增项。
