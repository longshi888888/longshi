# 小隆：公司问答Agent独立体验壳

2026-10-26，v0.7；状态：独立技术体验，非正式业务系统，不接生产数据。用户先体验桌面陪伴和问答，再把服务接进公司系统。范围与追踪见[计划与验收](计划与验收.md)，实测见[验证记录](验证记录.md)。

## 使用

本机项目外`xiaolong-agent-20261026/dist/小隆公司问答体验/`内的`小隆公司问答体验.exe`为启动入口。旁边的desktop-runtime、three、private-model都是运行所需文件，不能只复制EXE。整个文件夹约371MB，主要是Electron运行时。第三方文件、缓存和打包结果不进项目，角色仍为私有素材。

- 小隆出现在桌面右下，透明、无边框、置顶。拖顶部气泡移动；拖模型旋转；双击模型回正；下方下拉框换四档帽子。
- 点“聊聊／查业务”打开面板；“查业务”返回记录、金额差异和证据状态，“陪聊”用于交流。点“收起”回到桌面。右键小隆可退出或改变置顶。
- 软件“设置”里填自己的API地址、模型名、密钥，勾选使用模型并保存；默认DeepSeek兼容接口。密钥在当前Windows账户下加密保管，不回显；更换接口地址须重新提供密钥，避免发给错误服务。
- 没有密钥也能试玩，界面会明确写“本地演示路由，尚未调用模型”。有密钥时问题会发送给配置的模型服务；“测试接口”会实际发起一次API请求，按服务商规则计费。
- 会话仅在本机项目外保存最近20条，陪聊请求使用最近6条陪聊上下文；称呼和帽子偏好可保留。这是有限会话记忆，不是已实现公司知识库或自动学习。可清除会话、删除密钥。

先试：`查一下送货样本`、`查DEMO-A001`、`为什么有300和280两个金额？`、`已经到账了吗？`、`查DEMO-A999`、`全厂利润多少？`。所有业务日期、单号、产品和金额均为专门编造的数据。实际企业问法、身份权限和数据覆盖仍待调查。

## 以后接公司系统

`provider.py`定义受控业务工具与结构化结果，`agent.py`只负责选择工具／陪聊；`server.py`提供本机API，桌宠和面板调用同一个服务。正式迁移主要替换DemoProvider及宿主界面，补企业登录、数据权限、统计口径、版本和审计，不能只换数据库连接就宣布上线。

业务模式中，即使模型在自由文字里捏造数字，界面也只显示本地验证后的工具结果；模型仍可能选错工具或误解问题，不保证零错误。显式合成单号与模型参数不一致时停止返回。没有付款凭证返回“未知”，不是未付或零元。没有SQL执行、写业务数据或审批工具。

当前后台仅监听本机回环和随机会话路径，检查Host/Origin；界面禁用任意导航和新窗口，API密钥只由后台使用。运行状态、历史和凭据在用户目录下`.codex/tools/xiaolong-agent-20261026/runtime/`，不进入Git。Windows DPAPI密钥不能直接搬到另一用户／电脑后继续解密，需要重新填写。
