## 2. 报价部实际读到了什么

本轮处理报价部15份非锁文件：11份xlsx提取了全部页签保存值、公式及结构信息；4份旧式xls先作有限静态读取，随后复用协调窗口已调查配置的读取库重新读取普通页保存值。逐文件覆盖、区域与限制保存在私有报告。

协调窗口的双库对照在普通页保存值上未见差异，本窗口读取了该对照结果；这不证明公式正确或全部页签同等支持。两份文件的宏页在不同库的页签列表中存在差异，已保留为限制，没有当成空业务页或忽略。

人工重点核对了报价模式、计重与加工成本说明、板料／圆钢／组合报价模板、型号价格表、下单要求和业绩／利润表结构。旧式公式仅保存原始记录和缓存，未还原成Excel公式文字；内嵌图片、打印版式和全部计算效果未验证。未运行Office、宏、外链或公式重算，未修改原件。

## 3. 对业务理解的增量

| 新认识 | 对候选系统的影响 |
| --- | --- |
| 钢材／外协／模胚是业务分流；净尺寸、加余量、按件、材料加加工是不同报价模式 | 业务类型、报价模式、材料形状和价格用途分别表达，不能塞进一个分类 |
| 客户要求、报价计重、采购下料、加工公差有不同用途 | 相同材料不能套一个通用尺寸或余量规则；保留原条件及转换依据 |
| 对客价、采购／加工成本、单件费用和总量费用可能不同 | 先核用途、单位、客户／材料适用条件及版本，不把不同数值自动统一 |
| 部分表格保留旧日期、待填项及不同费用说明 | 报价日期、有效期、规则生效时间和资料更新时间分开；不自动选“最新文件”生效 |
| 模板有客户确认／签章文字，但没有补齐内部审批实例 | 工程审核、老板条件分支、对客报价、客户接受和正式下单继续分开 |
| 对外报价和内部成本辅助信息可能同在一个文件 | 外发按获准字段生成；打印区域不等于权限，不能直接开放整个内部工作簿 |
| 业绩看板日期可能来自自动日期公式 | 日期显示为今天不证明业务明细更新到今天；期间、截止日与更新时间分别说明 |

主管图中的三类报价继续保留。本批虽补出了材料和加工模板，尚未识别到明确的独立模胚专用模板证据；旧资料仍有模胚字段，不能因本次目录没有专表就删除该业务。

## 4. 不能直接写成正式规则的地方

- 部分模板的文字条件、基本公式及辅助列含义尚未完全一致，可能涉及成本与售价、单件与总量或不同适用版本，不能擅自修正。
- 下单说明中大／小加工条件存在重叠，实际优先级及文字是否有误待核；不自动改字或选择下单路线。
- 保存的公式错误、空值和零值不成为有效报价或经营事实；没有重算就不宣称兼容或计算正确。
- 旧式工作簿和部分定义名称含宏相关记录，只作静态资料读取，没有执行或据此认定功能。
- 稳定报价版本、订单明细映射、实际审核记录、现行价格及权限仍待核实，本次没有增加完整同单闭环。
