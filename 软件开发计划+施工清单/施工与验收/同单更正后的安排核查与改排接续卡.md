# 同一订单：更正后的原安排怎样核查和处置

## 先说明白这次要解决的工作

加工局部结果已经更正，但原安排仍包含S01/S02。系统把需要核对的S02指出来，由有权人员根据实际情况决定保持原安排、只改对应件或继续待核。**缺少当前加工依据不等于确认该件没加工，更不自动等于不能发货。** 加工、付款、装车、实际发出各有来源，不能由一个字段替公司决定。

“记录核查意见”只留核查人与依据，不改出货计划；“明确采用改排”才改变相应安排。核查意见不自动变放行，草稿不生效；不要求员工重抄没变的S01。

## 当前源里实际有什么、缺什么

F2同单的same_arrangements只有首次安排整行、version=1及order_id/scope_id；原操作凭据另存。scope来源是合成资格，不是当前加工/实际发出凭证。它没有已运行的逐件改排历史、当前采用版或本单实际发出写入协议。

旧独立replan_*用PD-W/J及自身安排/实际对象，已有普通“只改一件”证据；不是当前orders的O-ID。下一段须保可靠原安排身份与逐件映射，不能复制一份PDF/挂旧入口就说本单改排已接。

## 建议下一个限定例子

1. 从正常停止F2副本继承本单、原两件安排和已办更正；不动正在查看的W副本。
2. 若要实际演示改S02，必须另预置并明示“本例S02可调整且尚未实际发出”的具体依据与办理资格，再取基线。**当前实际发出未知，不能默认当0或未发。** 该预置不当公司放行制度，也不冒称已有普通实际登记。
3. 普通页面只选S02，填写新车次/时间和理由；S01原车/时间由当前有效安排承接。保存草稿与明确采用分开，原安排v1保历史，原操作/旧输出不改。
4. 若只记核查意见，计划件数/车次/版本不变；若缺实际或可改依据，仅保留意见/草稿，不办理正式改排。整单未知和真实交付条件不靠默认值补齐。

新结构需能表达“同一安排的原版、当前采用版、逐件范围和更改依据”。仅给same_arrangements.version加1或覆盖pieces会丢原版，不采用。具体实验表/命令先在项目外设计，未冻结生产DDL。

## 下一段验收应看到什么

| 情况 | 应保留的结果 |
| --- | --- |
| 只记核查意见 | 原两件安排整行不变，意见另可追溯；不显示已放行/已发出 |
| 只改S02并明确采用 | S01未触部分按原当前版承接；S02新安排生效，原版、原因、范围及人可查 |
| 草稿/旧版/依据不明 | 草稿不改变当前安排；旧所见版或资格/适用依据变化拒绝办理，保未明操作供查回 |
| 已实际发出或状态未知 | 已发事实不能被普通改排覆盖；未知不当可改；读取/写入对同一范围的事实版本要核清 |
| 重试及角色 | 原操作核原范围后查回，重复不多办；局部资格不授别单/全日数据 |
| 读回及保护 | 本单看到明确件当前安排与原版，结果更正/原安排/任务/资料关系不串；测试源和未触行/对象保留，正常停资源 |

这只确定下一段的检查目标，不新增真实岗位制度、实际发货、自动通知、付款放行、生产访问或发布。G03/G04等暂缺仍集中保存，不发新问卷。
