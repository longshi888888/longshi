# 客户归属与人员交接设计

2026-10-27；revision 1；1号协调；proposed／业务关系与权限设计。依据[36组迁移清单](../需求与范围/基础功能迁移清单.md)B01—07/B21—24、[旧软件功能草图P03/P14](../页面与原型/基础版关键页面草图.html#p03)、[网络归属摘要](../../AI调研/公开接续/2026-10-26-网络与行政流程补充摘要.md)和[权限一致性研究](../../AI调研/技术调研/2026-10-26-订单进度权限与一致性职责补查.md)。没有实际移交、停号或授予权限。

## 1. 哪些已有依据，哪些继续待核

用户默认查看方向“员工自己／主管本部／老板全公司”保留；它不自动决定对象／协作例外、字段、确认更正／审批和原件输出权，也不等于公司已经批准具体软件制度。客户归属、业务员代码和公海／离职继承入口有旧图证据；未展示的实际领取／分配／继承效果不能凭菜单补造。

公海计时起点／保护期／限额、初始化与“或”条件实际效果、领取和交接资格／审批路由、具体接办范围均待相应依据。现有月数或常见CRM经验不是公司通用规则。暂缺继续内部集中，不新增业务问题／问卷，不把这些都冒称用户已答“暂时问不到”。

## 2. 需要分开的关系

| 关系 | 保存／表示什么 | 不自动意味着什么 |
| --- | --- | --- |
| 客户组织与联系人 | 客户身份、用于联络的联系人及关系 | 联系人记录不自动成为员工身份或登录账号 |
| 员工、部门／角色、业务员条目与登录账号 | 有依据的身份映射、各自状态及有效关系，保留历史代码 | 同名／近似代码不证明同一身份，认证／角色启用不等全部业务已授权 |
| 当前客户跟进 | 当前由谁／哪范围跟进，变动的申请／有据生效关系 | 不回写旧报价／订单作者、历史责任或业绩归因 |
| 订单／任务具体责任 | 对应在途业务和未完事项由谁接办，适用范围／时点 | 客户换人不证明所有订单任务已转完，更不代表订单完成 |
| 原件／字段／输出的当前授权 | 记录今天谁可读哪些对象、动作、字段及整件 | 拥有客户不等下载整件成本表或更正全部订单；来源存在也可能受限 |

业务主库保存稳定身份、当前关系、变更及来源版本；原件按已有存储方案保管。历史事实署名与今天可读范围分别处理，统计按明确口径读归属／期间，不跟着当前负责人盲重算。

## 3. 一次交接怎样办理，怎样少重复

虚构H-DEMO-001：示例客户甲当前跟进人是示例员工甲，拟交员工乙。尚未核资格／适用条件，因此当前仍甲；此例不构成公司移交制度。

1. 从可靠客户上下文带出已有信息，列明本次拟交的客户跟进、相关在途订单、未完事项及必要资料范围；无需重复手抄整套清单。
2. 有权者按本次规则核接办对象、当前关系／版本及所需条件；条件未齐保留申请，不改当前归属。
3. 规则允许且片段有据时可同一次明确办理；记录前后对象、范围、原因／依据、生效时点及结果。若存在独立接收／待办含义，分别显示，不强制统一多轮审批。
4. 后续业务按当前范围继续，未接办部分保留明确待处理。客户移交、订单责任、任务分派及资料可读范围不共用一个“全部完成”开关。
5. 历史记录不改成新人名下；当前访问按新权重核。账号状态可按其规则单独变更，不把客户全部交完当停号前置，也不因停号即称全部业务已移交。

所有办理均需当前可信身份与适用资格。管理员能维护技术账号不自动获业务归属／审批决定权；恢复账号不自动恢复全部旧权。已有会话、旧索引、文件直链、操作回执和输出领取不得绕当前授权；已交付副本不承诺远程收回。

## 4. 未来检查：当前只做纸面预期

| 虚构动作／条件 | 正确表现 | 错误表现 |
| --- | --- | --- |
| H-DEMO-001只保存申请 | 客户当前仍甲，拟交乙与待核可见；原订单／任务仍按各自已有安排 | 保存即转乙，全部订单／资料自动授乙 |
| 单独预给资格和范围后正式生效 | 只在已核范围改当前关系，保留旧责任／来源及生效时点，未涉及部分待办 | 全部过去订单／业绩改乙，部分失败仍显示全移交 |
| U-DEMO-A经有权动作停用，客户接手尚未落实 | 后续受限请求按停用策略处理，历史署名保留、未完范围待交接可查 | 删人同时删订单；先交完客户才允许停号；停号即称已转给主管 |
| 新接办人查历史／原件、旧用户查旧链接／输出 | 当前对象／动作／字段／整件及来源存在权一致；读不到不重新执行业务 | 自己曾署名就永远能读，客户归属自动授成本原件，旧缓存或回执绕撤权 |
| 一例预给只有一个当前主跟进者，两次互斥领取冲突 | 按该例确定规则核版本及结果，不最后写入静默覆盖；公司若允许协作则明确其关系 | 从两个请求自动造出未获准共同归属，或套用任意抢客胜负算法 |
| 同名客户／相似员工代码／未下单条件 | 提示有据候选／待核，不自动并客并号；按明确条件查询 | 同名合并，历史业务员等同登录号，未下单推从未成交／自动回收 |
